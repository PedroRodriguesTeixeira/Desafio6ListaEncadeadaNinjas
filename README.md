# 🥷 Gerenciador de Ninjas com LinkedList

Sistema em Java desenvolvido para gerenciar uma estrutura dinâmica de dados contendo informações de ninjas. Este projeto é a resolução prática do desafio de estruturas de dados proposto pela trilha **Java 10x**.

## 🎯 Objetivo do Projeto
Implementar e manipular uma lista de ninjas utilizando a estrutura nativa `LinkedList`. O sistema inicializa com sete ninjas pré-cadastrados — contendo os atributos de nome, idade e vila — e executa operações diretas nas extremidades e em índices específicos da lista.

## ⚙️ Funcionalidades Implementadas
* **Manipulação de Topo:** Adição de um novo ninja no início da lista e remoção do primeiro ninja da estrutura.
* **Busca Indexada:** Acesso aos dados de um ninja alocado em uma posição específica da coleção.
* **Listagem Dinâmica:** Exibição formatada de todos os elementos contidos na lista através de iteração.

## 🛠️ Tecnologias e Conceitos Aplicados
* **Estruturas de Dados:** Uso de `LinkedList` e seus métodos nativos de manipulação.
* **Orientação a Objetos:** Modelagem de Classes, Objetos, atributos e métodos `Getters` `Setters`.
* **Polimorfismo:** Sobrescrita do método `toString()` da classe mãe `Object` para garantir a legibilidade das informações no terminal.
* **Controle de Fluxo:** Utilização de Laços de Repetição (Loops) para varrer e ler os elementos da lista.

## 🚀 Como Executar
1. Clone este repositório em sua máquina local.
2. Abra o diretório do projeto em sua IDE de preferência (IntelliJ IDEA, Eclipse, VS Code).
3. Execute o arquivo `Main.java` para visualizar o resultado das operações de manipulação no console.
